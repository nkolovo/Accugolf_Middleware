Detailed Description

Base class of all adapters delivering chunks to an INodeMap.

Helper Port base class to implement managed ports.

Port base class to implement managed ports.

Base class of all adapters delivering events to an INodeMap.

In this port only the IntPtr related Read and Write methods must be implemented.

In this port only the array related Read and Write methods must be implemented.
